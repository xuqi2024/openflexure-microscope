# Swappable objective lenses for the high-resolution upright microscope

Instead of the standard high-resolution optics module, you will need to print:

* [upright_z_actuator_mount_16mm_sample.stl](models/upright_z_actuator_16mm_mount.stl){previewpage}. This replaces the standard z-actuator mount. 
* [swappable_rms_optics_module.stl](models/swappable_rms_optics_module.stl){previewpage} - print this in black!
* [swappable_rms_mount.stl](models/swappable_rms_mount.stl){previewpage}
* [swappable_rms_carrier_thin_jig.stl](models/swappable_rms_carrier_thin_jig.stl){previewpage}
* One per objective intended to be used: [swappable_rms_carrier.stl](models/swappable_rms_carrier.stl){previewpage}

Assembly instructions for the optics module, mount, and carrier can be found [here](upright_swappable_optics_module.md).

The upright_z_actuator_mount_16mm_sample should replace the standard upright z-actuator mount, to accommodate the additional height of the optics module.
