# 组装照明系统
显微镜通常通过观察穿过样品的光线工作 - 所以我们需要从上方照亮样品。本节将指导您组装照明臂。

# 需求
## 零件
*   1个[照明燕尾槽](./parts/printed/illumination_dovetail.md)
*   1个[聚光镜臂](./parts/printed/condenser.md)
*   1个[5mm LED](./parts/electronics/white_led.md)理想情况下连接到2路母接头
*   2个[M3x8内六角螺钉](./parts/fixings/m3x8mm_caphead_screw.md)
*   2个[M3垫圈](./parts/fixings/m3_washer.md)
*   1个[聚光镜](./parts/optics/condenser_lens.md)（可选）

## 工具
* 2.5mm内六角扳手
* [聚光镜插入工具](./parts/printed_tools/lens_tool.md)（如果使用聚光镜）

# 组装说明
## 步骤1
要构建聚光镜，您需要安装臂的两个部分、两个M3螺钉和垫圈、LED和电缆。如果您使用聚光镜，您还需要打印的镜头插入工具将镜头放入支架中。

## 步骤2
*这是可选步骤。如果您不使用聚光镜，跳到步骤3*

将聚光镜放在插入工具上（平面向下），将聚光镜外壳向下推到其上。注意保持垂直。您可能需要用相当大的力推。与光学模块中的管镜一样，检查它是否平坦，如有必要再次推。
![带插入工具的聚光镜模块](./images/insert_condenser.jpg)
![](./images/condenser_lens_1.jpg)
![](./images/condenser_lens_2.jpg)

## 步骤3
将LED插入聚光镜外壳中。它应该推入配合并保持在位。如果不能保持，可以粘贴或用胶带固定。
![](./images/insert_led.jpg)

## 步骤4
_注意：Openflexure工业套件提供预组装的带电阻LED，所以您可以跳过此步骤。_

如果您还没有焊接，为LED组装电缆。您只需要能够点亮它 - 我们通常通过将LED焊接到电阻（约80欧姆），然后连接约20cm末端带母插头的电缆来做到这一点。这可以轻松插入树莓派的5v GPIO引脚。

## 步骤5
将照明燕尾槽放在显微镜本体的平台上，用两个M3螺钉固定就位。在螺钉和燕尾槽之间使用垫圈。显微镜上的孔应该正好适合M3螺钉的大小，但您可能需要用一些力才能拧入螺钉。但是，要小心在燕尾槽紧密安装后立即停止转动螺钉 - 否则您可能损坏螺纹。

![安装照明平台](./images/mount_illumination_dovetail.jpg)

## 步骤6
将聚光镜的水平部分夹在垂直燕尾槽上。

![滑入聚光镜](./images/slide_on_condenser.jpg)

## 步骤7
将LED的电缆整齐地穿过聚光镜和燕尾槽之间的间隙，然后沿着光学模块向下到显微镜底部。不要让它穿过平台中心的孔 - 让它在载物台和燕尾槽之间通过。

## 步骤8
您已经组装了照明系统 - 快完成了！
