# Using a Logitech C270 HD USB webcam as a basic optics module

This section describes how to assemble an optics module consisting of a Logitech C270 HD webcam and the lens from the camera. To create a microscope the wide angle lens is reversed and separated from the camera. This makes quite a good microscope objective with a resolution of around 2μm.

>i USB cameras are not supported in the standard Openflexure software.
