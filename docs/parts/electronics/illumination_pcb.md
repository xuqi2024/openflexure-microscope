# Illumination PCB

As of version 7, the OpenFlexure Microscope uses a PCB rather than just an LED.  More information, and comparison data, is in the [illumination optics explanation].

If you are using the [Sangaboard v0.5] as a motor controller, you can use the latest version of the illumination board, design files for this board are in [ofm-led repository], a completed board can be purchased as part of the illumination kit at [taulab.eu].

If you are using the motor workaround or an older Sangaboard, you can use the PCB with built-in current regulation, which can be previewed and ordered via [kitspace], and all design files are available in its [repository].

If you are unable to get hold of a PCB, it is possible to mount a 5mm LED into the condenser instead, using the [instructions for the LED workaround].
