## 构建类型选择

### 基础版本（教育用）
- 使用 `2a_basic_optics_module_zh.md` 中的说明
- 适合学校和业余爱好者
- 成本最低，分辨率约2微米

### 高分辨率版本（研究用）  
- 使用高分辨率光学模块（待翻译）
- 适合科学研究和医疗应用
- 需要显微镜物镜和管镜

### 电机化版本
- 在基础版本基础上添加电机系统
- 支持自动控制和远程操作
- 需要额外的电机和控制板
