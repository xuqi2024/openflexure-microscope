# OpenFlexure显微镜 - 组装说明
OpenFlexure显微镜是一台可3D打印的显微镜，配备了高精度的机械载物台。它可以配备基于网络摄像头的基础光学系统，或基于传统显微镜物镜的高价光学系统以获得更高的图像质量。它还可以电机化。这些说明将指导您如何组装显微镜的光学和机械部件。

## 打印零件

通过[显微镜STL配置器]页面配置您的显微镜硬件并下载STL文件。[打印零件](./0_printing_zh.md)详细描述了零件和打印设置。

## 关于显微镜
OpenFlexure显微镜是一台可定制的光学显微镜，使用极其便宜的网络摄像头光学系统或实验室级的RMS螺纹显微镜物镜。它采用倒置几何结构，配备高质量的机械载物台，可使用低成本齿轮步进电机进行电机化。

描述这项工作的原始论文可从[科学仪器评论](http://dx.doi.org/10.1063/1.4941068)开放获取，您可以阅读各种[媒体文章](https://github.com/rwb27/openflexure_microscope/wiki/Media-Articles)以获得更用户友好的介绍。

光机械学是任何显微镜的关键部分；在高倍放大率下工作时，保持样品稳定并能够精确对焦是至关重要的。使用打印机械零件进行精确运动控制极其困难，因为良好的线性运动通常需要严格的公差和光滑的表面处理。这种3D打印显微镜载物台的设计使用塑料柔性机构，意味着其运动无摩擦和振动。当由微型步进电机驱动时，它能实现远低于100nm的步进，并在几天内稳定在几微米范围内。

这种设计旨在最小化打印后组装所需的工作量，以及所需的非打印零件数量 - 部分是为了使打印尽可能简单，部分是为了最大化稳定性；显微镜的大部分（包括所有带柔性机构的零件）都打印为一个整体。主要费用在于树莓派及其相机模块；设计只需要大约200g塑料和一些螺母、螺栓等其他零件。光学模块（包含相机和镜头）可以轻松更换或修改，例如通过使用显微镜物镜改变放大倍率/分辨率，或添加滤光立方体进行荧光观察。
