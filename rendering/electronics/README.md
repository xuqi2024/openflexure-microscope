This folder contains models of PCBs. These are generated by exporting VRML files from KiCAD, which contain the full model and color information but cannot be directly imported into OpenSCAD. The VRMLs are converted to 3MFs using Blender, which preserves the colors, but OpenSCAD's 3mf import doesn't support multicolor 3MFs. This is where the `process_3mf.py` script comes in: it splits the 3mf files into a file per color by removing triangles of different colors. OpenSCAD should be able to import these, but it segfaults on these files. A tool https://github.com/lemgandi/3mf2stl is used to convert these 3mfs to stls which can finally be imported into openscad.
It is possible that the 3mfs generated by `process_3mf.py` are not fully up to spec and this causes the segfault, but they can be opened in other tools, just not openscad.
